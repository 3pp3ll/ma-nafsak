# مع نفسك

سولف مع نفسك، واحتفل بكل إنجاز. هذا المستودع فيه النسخة التجريبية للتطبيق كصفحة ويب، وبعدها يتحول لتطبيق Flutter.

## تجربتها على الجوال

1. من إعدادات المستودع: Settings ثم Pages.
2. في Source اختر Deploy from a branch، والفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة تفتح على `https://3pp3ll.github.io/ma-nafsak/`.
4. ثبّتها كتطبيق: آيفون (Safari) زر المشاركة ثم «إضافة إلى الشاشة الرئيسية»، وأندرويد (Chrome) القائمة ثم «تثبيت التطبيق».

## ملاحظات النسخة التجريبية

- خارج Claude، السوالف تشتغل بردود جاهزة، والبيانات تنحفظ في المتصفح فقط.
- لوحة التحكم مخفية: اضغط على شعار الرأسين فوق 5 مرات ورا بعض، وادخل الإيميل وكلمة المرور.
- رابط التجربة: من لوحة التحكم ← مفاتيح الذكاء، حط مفتاح OpenRouter وانسخ رابط التجربة. اللي يفتح الرابط يشتغل عنده الذكاء الاصطناعي بحد رسائل يومي. المفتاح ما ينحفظ في المستودع. الدخول هنا للعرض فقط، والحماية الحقيقية تكون من السيرفر في التطبيق.
- لا تحط مفاتيح ذكاء اصطناعي حقيقية في الصفحة.

## Supabase: التسجيل وتفعيل الإيميل وتقرير الاستخدام

1. سوّ مشروع في supabase.com (أو استخدم مشروع موجود).
2. SQL Editor ← New query ← الصق ملف `supabase/setup.sql` كامل ← Run.
3. Authentication ← Sign In / Providers ← Email: خلّ «Confirm email» مفعّل.
4. Authentication ← URL Configuration: حط Site URL = `https://3pp3ll.github.io/ma-nafsak/` وأضفه في Redirect URLs.
5. Authentication ← Emails ← SMTP Settings: اربط خدمة إيميل (مثل Resend أو Brevo). خدمة Supabase المجانية ما ترسل إلا لإيميلات فريق المشروع وبعدد قليل جداً.
6. Project Settings ← API (أو Data API): انسخ Project URL ومفتاح anon public، والصقهم في التطبيق: لوحة التحكم ← مفاتيح الذكاء ← تجميع الاستخدام، وبعدها انسخ رابط التجربة من جديد.

اللي تشوفه بعدها:
- لوحة التحكم ← تقرير الاستخدام: عدد اللي سجّلوا وفعّلوا وقبلوا الأخبار، والاستخدام الأسبوعي.
- Supabase ← Table Editor ← profiles: الإيميلات ومين وافق على الأخبار.
- Supabase ← Table Editor ← plan_requests: طلبات باقة بلس.
